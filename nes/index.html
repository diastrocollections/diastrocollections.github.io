A note from the curator

The NES has the largest, messiest library in this whole series — nearly 700 licensed games in North America alone — which makes curating exactly 100 the hardest editorial job yet. This collection spreads across Nintendo's own foundational classics, Capcom and Konami's golden run of licensed platformers, an unusually deep run of Japan-built RPGs (several of which, it turns out, never crossed the Atlantic at all), graphic adventures nobody remembers were on a Nintendo console, and a handful of genuine PAL- or NA-exclusive curios.

Following this project's standing convention, release years lead with the European release where one exists, with the Japanese and/or North American year noted secondarily. Where a game never received a European cartridge release at all — which turned out to be true for a striking number of NES titles, especially Japan-built RPGs — the North American (or, rarely, Japanese-only) year is shown instead with an explicit note, rather than defaulting silently to a EU year that never happened.

One thing this page deliberately does not do is flag PAL 50Hz slowdown on a per-game basis: virtually every early NES game shipped on European hardware locked to 50Hz with letterboxed borders and a real, audible speed reduction, since almost nothing on this console got a dedicated PAL-optimized build the way some later platforms occasionally did. Rather than repeat that footnote a hundred times, treat it as true by default for anything below with a European release — it isn't a story worth telling game by game.

Every title below was individually fact-checked for release-platform accuracy, developer attribution, and actual regional availability — the most common error caught was, again, a publisher (Taito, Irem, SNK, Jaleco, Sir-Tech) credited as the developer when a different studio actually built the specific NES version.

Regional-exclusivity curios worth knowing

  • Elite (1991) — released only in Europe. No North American or Japanese NES release ever happened, a rare full reversal of this collection's usual pattern.
  • Gimmick! (1992 Japan, 1993 as "Mr. Gimmick" in Scandinavia only) — Sunsoft of America rejected it for North America outright; it never released there.
  • StarTropics (1990) — never released in Japan at all, one of the few Nintendo-published NES games built exclusively for the West.
  • R.C. Pro-Am (1988) — also never released in Japan, day-and-date in North America and Europe instead.
