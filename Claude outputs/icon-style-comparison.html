Hub tile icon — three directions

Same five tiles, same tile card, same fonts and colors as the live hub — only the icon in the top-left badge changes. NES, SNES, N64, PlayStation, and Game Boy Color were picked to span cartridge, disc, and handheld hardware, plus a wide accent-color range.

A Reuse each platform's own motif

Shrinks each collection's already-established hardware identity into icon form: PS1's controller-button glyphs, N64's four-color logo swirl, SNES's four-button accent stripe, GBC's rainbow shell, NES's cartridge-red label.

B Clean minimal silhouettes

One consistent icon language: a flat single-color outline of each platform's actual hardware form factor — cartridge, controller, disc, handheld body — tinted with that platform's accent color.

C Retro pixel-art icons

Chunky 8-bit-style pixel glyphs of the same hardware shapes as style B, leaning into the site's retro-gaming personality instead of a modern flat-icon look.

Note: these are quick sketches to help pick a direction, not final art — once you choose a style (or mix, e.g. A's concept drawn with B's clean linework), the next step is building all 12 properly and wiring them into data/platforms.json in place of the emoji icon field.
